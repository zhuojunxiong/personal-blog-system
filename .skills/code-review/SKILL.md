# Code Review Skill

状态：已建立项目化入口

用途：辅助代码 Review、文档 Review、风险识别、测试缺口识别和记录整理。

## 触发场景

当完成代码、文档、测试、UML、AI 协作记录或交付材料变更后，使用本 Skill 做交付前检查。

## 必读材料

1. `AGENTS.md`。
2. 本轮 CR、需求、设计和测试记录。
3. `git diff` 或变更文件清单。
4. `docs/10_代码Review记录.md`。
5. `docs/11_AI协作记录.md`。

## 工作步骤

1. 确认变更是否对应明确需求或 CR。
2. 检查是否误改业务代码、删除文件、同步外部目录或复制无关资源。
3. 检查需求、设计、实现、测试、Review、AI 协作记录是否闭环。
4. 按严重程度列出风险。
5. 标注未执行测试、需人工确认和后续补齐项。
6. 将结果追加到 Review 记录或最终交付检查清单。

## 输出格式

```markdown
## Review 记录

- 关联 CR：
- 变更范围：
- 主要发现：
- 测试状态：
- 风险等级：
- 需补材料：
- 是否建议提交：
```

## 禁止事项

1. 不直接重构。
2. 不伪造测试通过。
3. 不把建议写成已完成。
4. 不读取或修改 `software-practice-records`。
5. 不提交老师资料包、jar、字体、缓存或无关二进制资源。
