# DOCX Design Skill

状态：已建立项目化入口

用途：辅助概要设计说明书、系统设计说明和课程交付设计文档整理。

## 触发场景

当需要补充概要设计、整理架构说明、准备设计文档导出或答辩说明时，使用本 Skill。

## 必读材料

1. `AGENTS.md`。
2. `docs/03_v0.5.1架构追溯.md`。
3. `docs/05_技术路线决策报告.md`。
4. `docs/06_ADR/`。
5. `docs/08_概要设计说明书.md`。

## 工作步骤

1. 读取已确认需求和当前代码事实。
2. 整理系统边界、模块划分、数据模型、接口或路由关系。
3. 判断是否需要新增或更新 ADR。
4. 标注设计建议、已实现事实、待验证和需人工确认。
5. 若实际导出 docx，记录输入、输出、执行结果和人工确认。

## 输出内容

1. 设计文档补充建议。
2. 模块和数据关系说明。
3. ADR 判断。
4. 测试关注点。
5. docx 导出记录，若实际执行。

## 禁止事项

1. 不更换 Flask + Jinja2 + SQLAlchemy + SQLite 技术路线。
2. 不把设计建议写成已实现。
3. 不伪造 docx 导出结果。
4. 不复制教师资料全文。
5. 不提交 jar、字体、缓存或无关二进制资源。
