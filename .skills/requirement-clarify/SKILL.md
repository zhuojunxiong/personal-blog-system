# Requirement Clarify Skill

状态：已建立项目化入口

用途：辅助需求澄清、需求拆解、范围收敛和验收标准整理。

## 触发场景

当用户提出新功能、流程变更、页面改版、AI 能力调整、数据库变化或课程交付材料补充时，先使用本 Skill 辅助澄清。

## 必读材料

1. `AGENTS.md`。
2. 本轮用户需求。
3. 相关 `docs/change-requests/`。
4. `docs/02_v0.5.1需求追溯.md` 和 `docs/07_需求规格说明书.md`。
5. 如涉及教师资料融入，读取 `docs/13_教师Agent与Skill融入说明.md`。

## 工作步骤

1. 判断需求是否已有 CR。
2. 明确目标、使用者、场景和验收标准。
3. 列出不纳入范围。
4. 标注已确认、待补齐、需人工确认。
5. 判断是否需要转交 Architect、Tester 或 Reviewer。
6. 将结果写入 CR、需求规格或 AI 协作记录。

## 输出格式

```markdown
## 需求澄清结果

- 背景：
- 目标：
- 纳入范围：
- 不纳入范围：
- 验收标准：
- 影响文档：
- 是否需要 ADR：
- 是否需要测试记录：
- 需人工确认：
```

## 禁止事项

1. 不写业务代码。
2. 不更换技术栈。
3. 不把未来计划写成当前实现。
4. 不复制教师资料全文。
5. 不读取或修改 `software-practice-records`。
