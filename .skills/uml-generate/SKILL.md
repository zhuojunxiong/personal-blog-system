# UML Generate Skill

状态：已建立项目化入口

用途：辅助生成和维护 PlantUML 源文件、UML 说明和图示验收记录。

## 触发场景

当需求规格、概要设计、答辩材料或架构说明需要用例图、类图、活动图、时序图或部署说明时，使用本 Skill。

## 必读材料

1. `AGENTS.md`。
2. `docs/07_需求规格说明书.md`。
3. `docs/08_概要设计说明书.md`。
4. `docs/03_v0.5.1架构追溯.md`。
5. 当前代码中的模型、路由和服务事实。

## 工作步骤

1. 先确认图的目标和受众。
2. 只基于当前代码和正式文档生成图示内容。
3. 优先维护 PlantUML 源文件，不提交老师资料包中的 `plantuml.jar`。
4. 渲染图片前确认环境；未渲染则标注为“仅生成源文件”。
5. 渲染后记录输入源文件、输出图片、执行结果和人工确认。

## 输出内容

1. PlantUML 源文件建议。
2. 图示说明。
3. 渲染状态。
4. 与需求或设计文档的追溯关系。

## 禁止事项

1. 不提交 `plantuml.jar` 或大型二进制工具。
2. 不把未渲染图片写成已生成。
3. 不让图示超出当前实现事实。
4. 不复制教师资料全文。
5. 不读取或修改 `software-practice-records`。
