# 稷下：AI 驱动的知识写作与搜索平台

本项目是软件综合实践课程项目，定位为 **AI 驱动的知识写作与搜索平台**。

## 产品定位

系统服务两类用户，核心解决一个问题：

> 知识被写出来之后，怎样被真正需要它的人找到？

**写作者**用 Markdown 整理知识、项目经验和学习笔记，AI 辅助查资料、列大纲、润色正文，发布时自动生成搜索用 AI 摘要。

**阅读者**用自然语言搜索问题，系统基于 AI 理解匹配最相关的文章，展示推荐理由和文章特征。

**主线闭环**：写作 → AI 总结 → 自然语言搜索 → 阅读 → 互动反馈。

## 核心功能

### 1. 自然语言搜索（主入口）

首页 `/home` 提供极简搜索入口。用户不需要先选分类或知道标题，只需描述问题，系统完成：
- 理解用户真实搜索意图
- 从所有文章中找出最相关内容
- 说明每篇文章的推荐理由和相关性

搜索结果包含：文章标题、AI 搜索摘要、匹配原因、关键标签、作者、点赞/收藏/评论数据。

### 2. Markdown 写作工作台

写作页提供干净、清晰的写作环境：
- 左侧：标题、摘要、Markdown 正文、发布设置
- 右侧：AI 助手（4 个核心能力）

AI 助手能力：
| 功能 | 说明 |
|------|------|
| 搜资料 | 上网搜索相关网页，AI 整理为写作参考资料 |
| 整理大纲 | 从正文提取或生成文章大纲结构 |
| 润色正文 | 修正语病、优化表达，保留作者风格 |
| 生成搜索摘要 | 提取文章特征，用于搜索系统检索 |

### 3. 发布后 AI 自动摘要（闭环关键）

文章发布时，AI 自动生成搜索用知识摘要，包含：
- 核心主题
- 解决的问题
- 关键知识点
- 可能的搜索问题
- 推荐理由

AI 不可用时使用本地降级摘要，不阻断发布。摘要进入普通搜索和 AI 搜索候选召回范围。

### 4. 文章阅读与互动

文章页保持简洁，主要功能：
- Markdown 渲染正文阅读
- AI 搜索摘要展示
- 作者信息与知识主页入口
- 点赞（表示有帮助）、收藏（表示以后想看）、评论（补充、提问、交流）

### 5. Markdown 个性化知识主页

每个用户拥有可自定义的知识主页，用 Markdown 编写：作者简介、研究方向、代表文章、学习路线、项目经历、知识地图。

### 6. 知识合集

原"专栏"定位调整为作者的知识合集。读者主要通过搜索找到内容，喜欢某个作者后进入主页查看合集。

分类和标签保留为后台管理和搜索辅助能力，前台弱化。

## 当前版本功能

已实现：
- `/` 首次进入页和 `/home` AI 搜索首页
- 自然语言搜索和 AI 智能搜索（意图理解 → 关键词扩展 → 语义重排）
- AI 搜索摘要生成与降级
- 文章标题、摘要、AI 搜索摘要、正文、作者、标签多字段搜索
- 用户注册、登录、退出
- 用户编辑个人资料和 Markdown 知识主页
- 用户创建和管理知识合集
- Markdown 写作与文章发布、编辑、删除
- 文章点赞、收藏、评论
- 同一用户不可重复点赞或收藏
- 用户个人中心
- 管理员后台（用户、文章、合集、分类、标签、评论管理）
- AI 调用日志记录
- Markdown 正文和 Markdown 个人主页渲染
- 基础端到端测试

暂未实现：付费、广告、热榜、私信、关注、复杂推荐、向量检索、流式 AI 输出。

## 技术栈

Python / Flask / Flask-Login / Flask-SQLAlchemy / SQLite / Jinja2 / Bootstrap 5 / 原生 CSS

## 日常启动

```bash
cd personal-blog-system
.venv/bin/python run.py
```

访问 `http://127.0.0.1:5000/`（首次进入页），后续访问回到 `http://127.0.0.1:5000/home`。

## 首次运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

数据库已内置在仓库中，无需额外初始化。

## 数据安全

演示数据（56 位用户、114 篇文章）随仓库分发，以下操作**不会**丢失数据：

| 场景 | 结果 |
|------|------|
| 正常启停 | ✅ 完好 |
| 代码修改后 Flask 自动重载 | ✅ 完好 |
| 换电脑 / 别人 clone | ✅ 仓库自带 |
| `pytest tests/` | ✅ 用内存库，互不影响 |
| `python test_e2e.py` | ✅ 不删已有表 |

**唯一会清空数据的操作**：`python scripts/init_db.py --reset`

即使误操作清空了，一行命令即可恢复：

```bash
git checkout instance/personal_blog.sqlite
```

## 演示流程

**游客流程**：
1. 打开 `/` 进入首次页，点击进入系统
2. 在 `/home` 用自然语言搜索问题
3. 查看 AI 理解、推荐理由和搜索摘要
4. 进入文章阅读页、查看 Markdown 正文
5. 查看作者知识主页

**写作者流程**：
1. 登录后进入个人中心
2. 创建知识合集、编辑 Markdown 知识主页
3. 用 AI 助手搜资料、列大纲、润色正文
4. 发布文章，系统自动生成搜索摘要
5. 文章进入搜索，被其他用户通过自然语言找到

**管理员流程**：
1. 登录后台查看仪表盘
2. 管理用户、文章、合集、分类、标签、评论

## AI 功能说明

接入 DeepSeek 的 OpenAI 兼容 Chat Completions 接口：

```bash
export AI_API_KEY="你的 DeepSeek API Key"
.venv/bin/python run.py
```

4 个核心写作能力和 3 个搜索能力独立配置温度和 max_tokens。未配置 API Key 时使用本地降级，不阻断正常功能。
