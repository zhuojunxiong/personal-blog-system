# Archive 归档目录

本目录存放历史资料，**不直接代表当前项目事实**。在正式文档中引用这些材料时，必须注明其所属历史阶段。

## 目录结构

| 路径 | 内容 | 说明 |
|---|---|---|
| `old_docs/` | 历史开发记录和版本发布说明 | day1-4 开发记录、v0.4.1 设计/实施规则、v0.5/v5.1 发布说明、00_docs_inventory（早期文档盘点） |
| `old_prompts/` | 旧版提示词 | AGENTS_v0.1_legacy.md（v0.1 阶段治理章程，已被当前 AGENTS.md 取代） |
| `teacher_notes/` | 教师资料占位 | 预留，当前为空 |

## 使用规则

1. 归档文件保留原貌，不修改内容。
2. 在正式文档中引用归档材料时，标注「历史记录，需人工确认是否仍适用」。
3. 归档材料中的「已完成」「已验收」等结论，不等于当前版本的实现状态。
4. 新的历史文件归档时，应先确认引用关系，再移动。
