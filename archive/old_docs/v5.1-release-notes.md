# V5.1 版本迭代文档

> 文档类型：版本迭代总结
> 项目名称：多用户知识专栏博客系统「稷下」
> 当前版本：V5.1
> 技术栈：Flask + Jinja2 + SQLAlchemy + SQLite + DeepSeek API
> 版本主题：AI 智能搜索 + 丰富演示数据 + 开箱即用体验

---

## 一、版本背景

V0.5 完成了 DeepSeek AI 的真实接入（摘要、标签、润色、大纲、标题、问答六大功能），但搜索仍停留在 SQL ILIKE 关键字匹配阶段。用户必须输入精确关键词才能找到文章，无法用自然语言描述需求。

同时，演示数据仅 4 个用户、8 篇文章，覆盖行业太少，难以展示 AI 智能搜索跨行业理解的优势。启动流程也过于依赖终端环境变量手动设置。

V5.1 的核心目标：**让 AI 理解用户的搜索意图，即使用自然语言写出不精确的搜索词也能找到需要的文章**。同时大幅扩充演示数据、优化启动体验。

---

## 二、版本定位

> 在 V0.5 的 AI 写作辅助基础上，新增 AI 智能搜索能力，将搜索从关键词匹配升级为语义理解。丰富演示数据覆盖 50+ 行业。优化启动流程实现 .env 一键配置。

本版本不是架构迁移版本，也不改变现有 AI 写作功能的接口。

本版本解决的核心问题：

1. 搜索只能用精确关键词，不理解用户意图
2. 演示数据太少，缺少跨行业内容多样性
3. 启动需要终端手动 export 环境变量，体验繁琐
4. 缺少完整的跨平台启动教程
5. 前端搜索页面 AI 搜索状态展示不完整

## 四、AI 智能搜索

### 4.1 架构

三阶段管道，每阶段独立可降级：

```
用户输入 → [阶段1] AI 意图理解 + 关键词扩展
       → [阶段2] SQL 多关键词搜索（最多 20 篇候选）
       → [阶段3] AI 语义重排序 + 生成推荐理由
       → 返回结果（含 AI 理解卡片 + 每篇推荐理由 + 相关性评分）

任何阶段失败 → 自动降级到传统 ILIKE 搜索
```

### 4.2 阶段 1：意图理解（search_intent）

调用 DeepSeek API，分析用户的自然语言搜索输入，返回：
- `intent`：意图类型（技术学习/问题解决/经验分享/概念理解/工具推荐/其他）
- `keywords`：3-8 个扩展关键词（同义词、相关术语、中英文对照）
- `understanding`：一句自然语言描述（20-50 字），展示在搜索页顶部

参数：`max_tokens=800, temperature=0.3`

### 4.3 阶段 2：多关键词 SQL 搜索

使用阶段 1 返回的扩展关键词，对 Article 表 7 个字段做 OR ILIKE 搜索，合并去重取前 20 篇候选。复用现有 `ArticleService.search_published()` 的查询模式。

### 4.4 阶段 3：语义重排序与推荐理由（search_rerank）

将候选文章（id/title/summary/author/tags）和原始查询一起发送给 AI，AI 按语义相关性重新排序，排除不相关文章，为每篇写推荐理由。

参数：`max_tokens=2000, temperature=0.3`

### 4.5 降级策略

| 失败点 | 行为 |
|--------|------|
| 阶段 1 失败 | `keywords = [原始query]`，继续阶段 2 |
| 阶段 2 无结果 | 返回空结果 |
| 阶段 3 失败 | `fallback=True`，按原始排序返回不加推荐理由 |
| AI 完全不可用 | 前端跳转传统 `/search?q=...` |

## 六、启动体验优化

### 6.1 .env 自动加载

- `run.py` 新增 `python-dotenv` 自动加载 `.env` 文件
- `.env.example` 提供配置模板，复制重命名为 `.env` 即可使用
- `.env` 已在 `.gitignore` 中排除，不会提交 API Key

### 6.2 一键启动脚本

`启动项目.bat` 双击即可：
1. 检查虚拟环境（已有则跳过创建）
2. 检查依赖（已安装则跳过 pip install）
3. 检查数据库（已存在则跳过初始化）
4. 检测 API Key 配置状态
5. 启动服务器

日常使用只需 `启动项目.bat` 或 `.venv\Scripts\python run.py`。

### 6.3 跨平台教程

`docs/startup-and-test-guide.md` 完全重写：
- Windows / Mac 双平台环境准备
- DeepSeek API Key 申请和配置
- 模型选择指南（deepseek-chat / deepseek-reasoner）
- 完整环境变量参考
- 14 个测试账号一览
- AI 搜索使用示例
- 验收流程和常见问题

### 6.4 依赖更新

`requirements.txt` 版本策略从精确匹配调整为最低版本：

| 变更 | 原因 |
|------|------|
| `Flask-WTF==1.2.2` → `>=1.2.0` | 1.2.2 在国内镜像不存在 |
| `requests==2.32.5` → `>=2.32.0` | 2.32.5 在国内镜像不存在 |
| `Werkzeug==3.1.8` → `>=3.0.0` | 放宽以兼容更多镜像源 |
| 新增 `python-dotenv>=1.0.0` | 支持 .env 自动加载 |

## 八、已知限制

1. **搜索分页**：当前 AI 搜索结果暂不支持分页（前端未实现分页导航），后续版本补充
2. **AI 搜索速度**：完整三阶段管道耗时 3-8 秒，取决于 DeepSeek API 响应速度
3. **文章数量**：133 篇接近但未达到目标的 200 篇，后续可持续扩充
4. **离线搜索**：AI 不可用时降级到 SQL 搜索，但降级时不保留 AI 理解卡片
