# 仓库结构导航

整理日期：2026-07-04

当前版本：**v1.0**（课程交付阶段）| 当前分支：`work/v1.0-course-delivery`

本文用于快速说明 `personal-blog-system` 当前仓库中各目录的职责、可信度和整理边界。

## 1. 一句话结论

当前仓库包含三类内容：

1. 当前系统代码和测试（事实最高优先级）。
2. v0.5.1 建立的正式文档链（07-04 已全部填充并同步代码事实）。
3. 历史开发记录（已归档至 `archive/old_docs/`）、教师 Agent/Skill 材料、输出物和占位目录。

## 2. 当前目录分区

| 路径 | 当前用途 | 可信度/维护建议 |
|---|---|---|
| `app/` | Flask 应用主代码，包含模型、服务、路由、模板和静态资源。 | 当前事实最高优先级；本轮不改业务代码。 |
| `tests/`、`test_e2e.py` | 自动化测试和端到端测试入口。 | 测试文件存在；当前执行结果需单独运行确认。 |
| `scripts/` | 初始化数据库、生成演示数据等脚本。 | 属于当前可运行能力的一部分；运行前需确认是否会重置数据。 |
| `config.py`、`run.py`、`requirements.txt` | 启动、配置和依赖入口。 | 当前运行事实的重要来源。 |
| `docs/` | 当前主仓库的正式文档、变更记录、产品重新基线化和系统理解材料。 | 当前文档事实第二优先级。 |
| `docs/06_ADR/` | 架构决策记录。 | 已有多份 ADR；后续架构变更应先补 ADR。 |
| `docs/change-requests/` | 需求变更和受控修改记录。 | 适合作为后续需求进入实现前的入口。 |
| `docs/system-understanding/` | 当前系统理解、路由、模型、风险和追踪表。 | 适合作为阅读代码前的辅助导航；仍需以代码核验。 |
| `docs/product-rebaseline/` | 产品重新基线化分析和下一版本范围建议。 | 属于治理/产品分析材料，不等同于已实现功能。 |
| `docs/skills-usage/` | Skill 使用说明、映射和日志。 | 属于 AI 协作治理材料，不替代代码或测试事实。 |
| `agent-prompts/` | 多 Agent 协作提示词（角色约束）。 | 定义 AI 角色边界；Agent 与 Skill 的区别见 `AGENTS.md` 第 8 节。 |
| `.skills/` | 项目化 Skill 工作流入口（用户触发）。 | 每个 Skill 定义触发场景、步骤、输出和禁止事项。 |
| `diagrams/` | PlantUML、drawio、图片等图示材料。 | 可支撑设计文档；当前图是否最新需人工确认。 |
| `archive/old_docs/` | 历史文档归档（day1-4、v0.4.1-*、v0.5/v5.1-release-notes、00_docs_inventory）。 | 只作为历史资料；在正式文档中引用时需注明历史阶段。 |
| `archive/old_prompts/` | 旧版提示词归档（AGENTS_v0.1_legacy）。 | 历史参考，不代表当前项目事实。 |
| `output/` | Word、PDF、PPT、图片等生成物输出目录。 | 适合放交付物生成结果；不建议作为事实源。 |
| `instance/` | SQLite 数据库等本地运行数据。 | 属于本机运行状态；不应直接写成通用交付事实。 |

## 3. 推荐阅读顺序

新协作者或 AI 进入项目时，建议按以下顺序阅读：

1. `AGENTS.md`：先确认治理规则、Agent/Skill 体系、事实源优先级和禁止事项。
2. `README.md`：了解系统定位、启动方式、主要功能和目录概览。
3. **本文档**（`docs/00_仓库结构导航.md`）：确认目录分区和材料可信度。
4. `docs/15_AI驱动知识写作与搜索平台产品论述.md`：理解当前产品总纲、核心闭环和功能取舍。
5. `docs/01_v0.5.1现状盘点.md`：了解当前阶段状态。
6. `docs/02_v0.5.1需求追溯.md`：查看 F001-F050 需求和实现状态。
7. `docs/03_v0.5.1架构追溯.md`、`docs/08_概要设计说明书.md`：理解架构和模块关系。
8. `docs/09_测试报告.md`、`docs/10_代码Review记录.md`、`docs/11_AI协作记录.md`：查看验证和协作证据。
9. 历史版本演进：查看 `archive/old_docs/` 中的 day1-4 开发记录和版本发布说明。

## 7. 当前结构的心智模型

```text
personal-blog-system/
├── app/                  当前应用代码（事实最高优先级）
├── tests/                当前测试
├── scripts/              当前运行和数据脚本
├── docs/                 当前正式文档和治理材料
│   ├── 00-12             正式交付主链路
│   ├── 06_ADR/           架构决策记录
│   ├── change-requests/  需求变更入口
│   ├── system-understanding/
│   ├── product-rebaseline/
│   └── skills-usage/
├── diagrams/             UML 和图示
├── agent-prompts/        Agent 角色提示词（角色约束）
├── .skills/              Skill 工作流入口（用户触发）
├── archive/              历史归档（旧文档、旧提示词）
├── output/               生成物输出
└── instance/             本地运行数据
```
