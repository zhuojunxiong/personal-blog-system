# 项目背景与开发方法说明

生成日期：2026-07-04（基于当前代码事实撰写）

## 1. 项目概述

**项目名称**：稷下（zjx）—— AI 驱动的知识写作与搜索平台

**项目类型**：软件综合实践课程项目

**当前版本**：v1.0（课程交付阶段）

**当前分支**：`work/v1.0-course-delivery`

**技术栈**：Python / Flask / Flask-Login / Flask-SQLAlchemy / SQLite / Jinja2 / Bootstrap 5

## 2. 项目定位

系统服务两类用户，核心解决一个问题：

> 知识被写出来之后，怎样被真正需要它的人找到？

- **写作者**：用 Markdown 整理知识，AI 辅助查资料、列大纲、润色正文，发布时自动生成搜索用 AI 摘要。
- **阅读者**：用自然语言搜索问题，系统基于 AI 理解匹配最相关的文章。

**主线闭环**：写作 → AI 总结 → 自然语言搜索 → 阅读 → 互动反馈。

## 5. 开发方法

### 5.1 半自动工程化开发体系

本项目采用「统一主仓库 + Agent + Skill + ADR + Git 小步提交 + 测试记录 + Review 记录 + AI 协作记录」的开发体系：

- **Agent**（`agent-prompts/`）：定义 AI 角色边界（需求分析、架构设计、前端、测试、审查）
- **Skill**（`.skills/`）：定义项目化工作流入口（需求澄清、UML 生成、代码审查、文档导出）
- **ADR**（`docs/06_ADR/`）：记录架构决策及其背景、方案、影响
- **CR**（`docs/change-requests/`）：受控需求变更入口

### 5.2 变更控制流程

```
用户需求 → CR（需求澄清）→ ADR（如需架构变更）→ 实现 → 测试 → Review → AI 协作记录
```

### 5.3 信息可信度优先级

1. 当前代码实现（`app/`、`config.py`、`run.py`、`scripts/`、`requirements.txt`、测试文件）
2. `docs/` 中的正式文档
3. `README.md`、`DESIGN_SPEC.md`
4. `archive/` 历史资料（仅作参考，不代表当前事实）

## 6. 当前代码能力概要

详见 `docs/01_v0.5.1现状盘点.md` 和 `docs/02_v0.5.1需求追溯.md`。

核心能力：
- 游客公开浏览（首页、搜索、文章、分类、标签、专栏、作者主页）
- 用户注册登录、资料维护、密码修改
- Markdown 写作工作台（含 AI 辅助：搜资料、大纲、润色、搜索摘要）
- 文章发布后自动生成 AI 搜索摘要（含本地降级）
- 自然语言 AI 智能搜索（意图理解 → 关键词扩展 → 语义重排）
- 评论、点赞、收藏互动
- Markdown 个性化知识主页
- 管理员后台治理
- 知识合集（原专栏）
