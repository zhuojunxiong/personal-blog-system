## 1. 项目需求总览

当前 v0.5.1 代码实际体现的系统定位是：面向课程实践的多用户知识专栏博客系统。系统已经从早期个人博客演进为支持游客阅读、普通用户创作与互动、管理员后台治理，并带有 AI 写作辅助和 AI 智能搜索接口的知识创作平台。

2026-07-03 追加追溯：

根据用户重新确认的产品方向、CR-009 和 ADR-005，当前项目后续基线收束为“AI 驱动的知识写作与搜索平台”。原有多用户、文章、评论、点赞、收藏、后台治理、分类、标签和专栏能力继续保留；前台主线调整为 `/home` 自然语言搜索、Markdown 写作、发布后 AI 搜索摘要、文章阅读互动和 Markdown 个性化主页。

当前代码可反向追溯出的需求范围包括：

1. 游客公开浏览：主页、发现页、文章列表、文章详情、分类、标签、专栏、作者主页和搜索。
2. 普通用户账号：注册、登录、退出、资料编辑、密码修改、个人中心。
3. 普通用户创作：创建/管理自己的专栏，发布、编辑、删除自己的文章，保存草稿。
4. 内容互动：评论、评论审核流、点赞、收藏，并通过数据库唯一约束避免同一用户重复点赞或收藏同一文章。
5. 管理后台：管理员管理用户、文章、专栏、分类、标签、评论和 AI 接口状态。
6. AI 能力：写作页存在摘要、标签、润色、大纲、标题建议、文章问答接口；搜索页存在 AI 智能搜索接口与前端入口；真实远程 API 调用代码存在，但本次未执行验证。
