# CR-002 教师 Agent 与 Skill 融入交付流程

## 0. 使用说明

本文用于记录 `work/v1.0-course-delivery` 分支下对教师提供的 Agent、Skill 和 Vibe Coding 流程资料进行项目化吸收的变更请求。

本文只创建变更请求，不代表相关 Agent、Skill、文档导出、UML 生成、视觉验收或测试流程已经全部实施完成，也不修改业务代码。

本文不读取、不引用、不同步、不修改 `software-practice-records`。教师资料仅作为课程交付方法参考，不复制原始 zip，不复制教师资料全文，不提交 jar、字体、缓存、HTML 或无关二进制资源。

本 CR 的目标是把教师课程资料转化为本项目可展示、可追溯、可答辩的工程协作能力，而不是无边界扩张功能、重写系统或更换技术路线。后续仍遵守 ADR-002 方案 B：保留 Flask + Jinja2 + SQLAlchemy + SQLite，在测试保护、需求确认和 ADR 约束下做受控局部修改。

## 1. 变更编号

- CR 编号：CR-002
- 状态：已确认

## 2. 变更标题

- 标题：教师 Agent 与 Skill 融入交付流程

## 3. 变更背景

- 背景说明：老师提供了 Agent、Skill、Vibe Coding 流程资料，项目需要将其转化为可展示、可追溯的课程实践能力。当前 v1.0 课程交付完整版不仅需要系统可运行、可演示、可测试，也需要说明本项目如何使用 AI Agent、Skill、Git、CR、ADR、测试记录和人工确认形成工程化协作闭环。
- 触发来源：
  - `AGENTS.md` 对多 Agent / Skill 工作流、AI 协作记录、人工确认、禁止事项和事实源优先级的约束。
  - `docs/change-requests/CR-001-下一版本启动与范围确认.md` 对 v1.0 课程交付完整版、文档链路、AI 协作记录、项目总结和交付闭环的范围确认。
  - `docs/11_AI协作记录.md` 对半自动工程化开发体系和 AI 输出边界的记录。
  - `docs/12_项目总结.md` 对 Agent + Skill + ADR + Git 小步提交 + 测试记录 + Review 记录 + AI 协作记录体系的阶段性总结。
  - VS Code 工作区外部参考资料目录 `第一次会议的资料` 中的教师课程资料。
- 当前问题或机会：
  - 当前仓库已经有 `agent-prompts/` 和 `.skills/` 骨架，但需要在 v1.0 交付材料中解释它们与教师资料的关系。
  - 教师资料中包含需求、设计、数据库、前端、测试、UML、需求/设计文档导出和 Vibe Coding 工作流，可作为课程答辩时展示 AI 协作方法的依据。
  - 必须区分“已阅读并纳入交付规划”“后续可项目化说明”“已实际运行验证”三类状态，不能把未实际使用的 Skill 写成已经深度使用。
