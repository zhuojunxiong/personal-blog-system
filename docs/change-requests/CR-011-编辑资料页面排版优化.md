# CR-011 编辑资料页面排版优化

## 0. 使用说明

本文记录 `work/v1.0-course-delivery` 分支下 `/me/profile` 编辑资料页面的排版优化请求。

本次变更只调整登录后编辑资料页的模板、样式和测试配置，不修改业务模型、Service、数据库字段、权限规则或技术栈。

## 1. 变更编号

- CR 编号：CR-011
- 状态：已确认

## 2. 变更标题

- 标题：编辑资料页面排版优化

## 3. 变更背景

- 背景说明：原 `/me/profile` 页面复用旧 `admin-panel` 表单样式，昵称、邮箱、简介和 Markdown 主页在大屏下挤压、错位，页面顶部还保留了全站导航、搜索框、用户入口和退出按钮，影响编辑场景的专注度。
- 触发来源：项目负责人反馈“这个界面这么奇怪”，并确认去掉顶部 `AI 搜索`、`文章`、`写文章`、搜索框、右上角用户和退出。
- 当前问题或机会：在不改变资料保存业务逻辑的前提下，将编辑资料页重排为更清晰的两栏表单，并为该页面使用极简顶部品牌栏。
