# CR_TEMPLATE 需求变更管理模板

## 0. 使用说明

任何较大需求变化都必须先填写 CR，完成需求、设计、数据库、测试、文档和 ADR 影响评估，并经过人工确认后，才能判断是否允许进入实现。

本模板只用于需求变更管理，不代表变更已经获批，也不代表可以直接修改业务代码。不允许绕过 CR、需求确认、设计确认、测试计划和人工确认，直接让 AI 修改代码。
