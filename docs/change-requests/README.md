# Change Requests (CR) 需求变更记录

本目录存放受控需求变更记录。所有较大需求变化必须先填写 CR，完成需求、设计、数据库、测试、文档和 ADR 影响评估，并经人工确认后，才能进入实现。

## CR 模板

使用 `CR_TEMPLATE.md` 创建新 CR，复制模板并填写各节内容。

## CR 生命周期

```
待填写 → 待确认 → 已确认 → 实现中 → 已完成
                   ↓
                 暂缓 / 拒绝
```

## 注意事项

- CR 不代表变更已经获批，只是变更请求的记录。
- `CR-001-待填写.md` 为旧版占位文件，正式内容以 `CR-001-下一版本启动与范围确认.md` 为准。
- 不允许绕过 CR、需求确认、设计确认、测试计划和人工确认，直接让 AI 修改代码。
