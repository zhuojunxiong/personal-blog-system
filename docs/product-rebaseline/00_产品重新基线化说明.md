# 产品重新基线化说明

## 1. 文档状态

待填写模板。

本文档用于建立后续重新走产品设计全流程的工作区说明。当前内容不代表新的产品设计已经完成，不代表新需求已经确认，不代表下一实现版本已经确定。

## 2. 工作区定位

`docs/product-rebaseline/` 是产品重新基线化工作区，用于在 `v0.5.1-governance` 工程治理基线之后，重新梳理产品定位、用户角色、核心场景、功能取舍、课程验收目标、设计决策和下一版本范围建议。

本工作区不替代 `docs/07_需求规格说明书.md`、`docs/08_概要设计说明书.md` 等正式文档。只有经过人工确认并同步进入正式文档或 ADR 的内容，才能作为后续实现依据。

## 3. 使用边界

1. 当前阶段只建立模板，不填写未确认的新设计。
2. 不把候选想法写成已确定需求。
3. 不把未来计划写成当前已实现能力。
4. 不修改业务代码。
5. 不修改 `docs/07_需求规格说明书.md`、`docs/08_概要设计说明书.md` 等正式文档。
6. 不读取、同步、覆盖或迁移 `software-practice-records`。
