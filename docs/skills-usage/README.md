# Skill 使用索引

本文档目录用于说明本项目如何使用教师 Skill 和 Vibe Coding 工作流，并记录它们与项目交付物之间的关系。

当前目录只保存项目化后的索引、映射和使用记录，不保存教师资料原文，不复制整个 zip，不提交 jar、字体、HTML、缓存文件或大型二进制资源。

## 使用原则

1. 事实源优先：以当前代码、`AGENTS.md` 和 `docs/` 正式文档为事实源，教师 Skill 只作为课程实践方法参考。
2. 不夸大使用程度：已经实际运行、已经产出文件、只是映射说明、计划使用，需要分开记录。
3. 文档先行：Skill 先服务于需求、设计、UML、测试、Review、AI 协作和课程交付说明，不直接触发业务代码修改。
4. 人工确认：Skill 生成或辅助整理的内容仍需要人工确认，不能替代代码事实、测试结果或项目负责人确认。
5. 最小纳入：只提交项目需要的 Markdown 索引和项目化说明，不提交大型二进制资源或无关示例工程。
6. 边界固定：本目录不读取、不引用、不同步、不修改 `software-practice-records`。

## 目录文件

| 文件 | 作用 |
| --- | --- |
| `README.md` | 说明本项目如何使用教师 Skill，以及使用边界。 |
| `skill_mapping.md` | 建立教师 Skill、Vibe Coding 工作流与项目交付物的映射。 |
| `skill_usage_log.md` | 记录哪些 Skill 已纳入哪些文档，哪些只是计划使用或待验证。 |
