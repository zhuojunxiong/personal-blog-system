# 当前系统总览

生成日期：2026-07-02

适用分支：`work/v1.0-course-delivery`

本文件用于帮助项目负责人先理解当前系统，不授权新增功能，不修改业务代码。本文依据当前仓库代码、`AGENTS.md`、CR-003、需求规格、概要设计、功能展示清单和教师 Agent 提示词整理；未读取或修改 `software-practice-records`。

## 1. 一句话定位

当前项目是一个基于 Flask + Jinja2 + SQLAlchemy + SQLite 的服务端渲染单体应用，业务上定位为“多用户知识专栏博客系统”。

通俗说，它不是一个前后端分离的大平台，也不是微服务系统。它是一个 Python Flask Web 应用：浏览器访问 URL，Flask 在服务器里查数据库、组织数据，再用 Jinja2 模板拼出 HTML 页面返回给用户。

## 2. 当前系统解决什么问题

当前系统围绕课程交付和博客主链路展开，已经形成五条主线：

| 主线 | 当前含义 | 代表需求 |
| --- | --- | --- |
| 游客浏览 | 未登录用户可以看首页、文章、分类、标签、专栏、作者主页和搜索结果。 | F001-F007 |
| 账号与个人空间 | 用户可以注册、登录、退出、编辑资料、修改密码、进入个人中心。 | F008-F012 |
| 创作闭环 | 登录用户可以建专栏、写文章、保存草稿、发布文章、管理自己的文章。 | F013-F015 |
| 互动与治理 | 用户可以评论、点赞、收藏；管理员可以审核评论和管理内容。 | F016-F025 |
| 工程交付与 AI 辅助 | 系统有初始化、测试脚本、基础安全、AI 写作/搜索接口和文档链路。 | F026-F050 |

## 3. 当前用户角色

| 角色 | 能做什么 | 当前状态 |
| --- | --- | --- |
| 游客 | 浏览公开页面、阅读已发布文章、使用传统搜索、查看分类/标签/专栏/作者主页。 | 主体已实现。 |

## 4. 当前主业务闭环

### 4.1 游客阅读闭环

```text
游客进入首页或发现页
-> 浏览文章、分类、标签、专栏或作者
-> 打开文章详情
-> 系统记录阅读量
-> 可继续搜索、收藏或评论；互动时需要登录
```

这条链路主要由 `app/public/routes.py`、`app/article/services.py`、`app/templates/v041/` 和 `app/templates/public/` 支撑。

### 4.2 用户创作闭环

```text
用户注册或登录
-> 进入个人中心
-> 创建专栏
-> 打开写作页
-> 选择分类、标签、专栏
-> 保存草稿或发布文章
-> 发布后文章进入公开阅读链路
```

这条链路主要由 `app/auth/`、`app/user/`、`app/column/`、`app/article/services.py`、`app/templates/user/write.html` 支撑。

### 4.3 互动和后台治理闭环

```text
登录用户提交评论
-> 评论默认待审核
-> 管理员进入后台评论管理
-> 审核通过、隐藏或删除
-> 前台文章页展示已审核评论
```

点赞和收藏走相似的登录用户路径，但不需要管理员审核。后台治理入口分散在多个模块中，统一依赖 `app/admin/decorators.py` 的 `admin_required()`。

## 7. 当前不要误解成已完成的内容

| 容易误解的点 | 正确口径 |
| --- | --- |
| “AI 接口代码存在” | 只能说明接口、服务和前端入口存在；真实远程调用成功需另行验收。 |
| “AiLog 字段存在” | 只能说明基础日志模型存在；采纳、问题标记、后台查看和统计未形成完整闭环。 |
| “个人中心有阅读页” | 当前最近阅读使用收藏记录临时代替；没有真实 `ReadingHistory` 模型。 |
| “有 E2E 脚本” | 只能说明测试脚本存在；当前是否通过要实际执行后记录。 |
| “有 CSS 和 v041 模板” | 只能说明有视觉实现基础；视觉一致性要浏览器截图或人工验收。 |
| “README 有启动说明” | 只能说明文档存在；当前分支和环境能否复现需实际验证。 |
