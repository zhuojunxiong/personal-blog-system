## 10. 课程演示建议主路径

1. 游客路径：`/` -> `/home` -> `/discover` -> `/articles/<slug>` -> `/search?q=Flask`。
2. 账号路径：`/register` -> `/profile` -> `/settings` -> `/me/profile`。
3. 创作路径：`/my/columns` -> `/write` -> 发布文章 -> `/articles/<slug>`。
4. 互动路径：文章页评论 -> 管理员 `/admin/comments` 审核 -> 前台查看。
5. 后台路径：`/admin/login` -> `/admin/dashboard` -> 用户、文章、分类、标签、专栏、AI 状态页。
6. AI 边界路径：`/write` 展示 AI 面板，`/ai/status` 或 `/admin/ai` 展示配置状态；真实调用需验收记录支撑。
