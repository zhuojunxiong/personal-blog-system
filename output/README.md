# Output 输出目录

本目录用于存放工具链生成的交付物，不作为项目事实源。

| 子目录 | 用途 | 状态 |
|---|---|---|
| `images/` | 渲染后的 UML 图片、截图等 | 待使用 |
| `pdf/` | PDF 导出物 | 待使用 |
| `ppt/` | 答辩 PPT 等 | 待使用 |
| `word/` | docx 导出物（需求规格说明书、概要设计说明书等） | 待使用 |

## 使用规则

1. 生成物放入对应子目录，源文件仍在 `docs/` 或 `diagrams/` 中维护。
2. 不要在 output/ 中直接编辑生成物——应修改源文件后重新生成。
3. 导出后应在 `docs/skills-usage/skill_usage_log.md` 中记录输入、输出和执行结果。
